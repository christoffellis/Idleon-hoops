# Assets

Three cropped images drive the detection. Keep the crops tight (no extra background) and take
them from a screenshot at any one game size. You do not need to note the size: `hoops-calibrate scale`
finds it and writes `reference.json`, and templates are rescaled to match the live game.

| File | What to crop |
| --- | --- |
| `ball.png` | The basketball (this also gives the player's position) |
| `hoop_panel.png` | The back panel of the hoop |
| `life.png` | One remaining life in the lives display (not an empty slot) |

`digits/` (0.png-9.png) and `reference.json` are generated by `hoops-calibrate digits` and `scale`.

`nyquist.png` is generated by `scripts/nyquist_demo.py` for the video.
